CISCO IOS (Internetwork Operating System) 
it is a command line OS (CLI). 

IoS has three modes. 

First Mode is called user mode. 
it is very restrictive and execute very few show commands only. 

hostanme> 

Second Mode is called previllege mode. 
in this mode you can execute all show commands, restart the device, save the configurations, delete the vlan.dat file. 

hostanme# 

Third Mode is called Global configuration mode. 
all types of configurations

hostanme(config)# 

How to switch between the modes from user to global configuration mode.
hostanme> enable
hostanme# configure terminal 
hostanme(config)#

How to switch between the modes from global configuration to user mode.
hostanme(config)# end
hostanme# exit
hostanme> 

Cofiguring IP addresses on the Router R1

Router> enable
Router# config terminal
Router(config)# hostname R1

R1(config)# interface g 0/1
R1(config-if)# ip address 192.168.1.254 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit

R1(config)# interface g 0/2
R1(config-if)# ip address 192.168.1.254 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit

R1(config)# interface g 0/0
R1(config-if)# ip address 203.0.113.1 255.255.255.252
R1(config-if)# no shutdown
R1(config-if)# exit

Cofiguring IP addresses on the Router R2

Router> enable
Router# config terminal
Router(config)# hostname R2

R2(config)# interface g 0/1
R2(config-if)# ip address 10.0.1.254 255.255.255.0
R2(config-if)# no shutdown
R2(config-if)# exit

R2(config)# interface g 0/2
R2(config-if)# ip address 10.0.2.254 255.255.255.0
R2(config-if)# no shutdown
R2(config-if)# exit

R2(config)# interface g 0/0
R2(config-if)# ip address 203.0.113.2 255.255.255.252
R2(config-if)# no shutdown
R2(config-if)# exit

Verifying the IP addresses on the Router
Router# show ip interface brief

Configuring Static Routing on Router1

R1(config)# ip route 10.0.1.0 255.255.255.0 203.0.113.2
R1(config)# ip route 10.0.2.0 255.255.255.0 203.0.113.2

Configuring Static Routing on Router2

R2(config)# ip route 192.168.1.0 255.255.255.0 203.0.113.1
R2(config)# ip route 192.168.2.0 255.255.255.0 203.0.113.1

Verifying the routing table on R1 and R2 
Router# show ip route


To view the entire configuration on Switch/Router

Switch/Router# show running-config
